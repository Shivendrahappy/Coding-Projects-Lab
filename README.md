# Coding Projects Lab  A collection of small coding projects built while learning Computer Science, Python, Algorithms, and Software Development.  ## Projects  

# Weekend Coding Lab (2026)

Goal:
Build one small project every weekend to learn programming, problem solving, and software development.

Rule:
A completed small project is better than an unfinished giant project.

---

Objective:
Automatically correct common typing mistakes.

Skills:

* Strings
* Dictionaries
* Functions

Examples:

havve → have
becuse → because

Future Upgrade:
Real-time web version.
